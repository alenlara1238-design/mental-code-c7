## Cálculo para institución educativa
### Enunciado del problema

Una institución educativa desea desarrollar un programa interactivo que permita a los estudiantes calcular el área de diferentes figuras geométricas de manera sencilla.

El sistema debe mostrar un menú con varias opciones para que el usuario seleccione la figura de la cual desea calcular el área. Dependiendo de la opción elegida, el programa solicitará los datos necesarios, realizará el cálculo correspondiente y mostrará el resultado en pantalla.

El programa debe permitir calcular el área de las siguientes figuras:
```text
* Rectángulo
* Círculo
* Triángulo
* Pentágono
```

El sistema debe ejecutarse de forma continua hasta que el usuario decida salir, mostrando nuevamente el menú después de cada operación. Además, debe manejar correctamente opciones inválidas ingresadas por el usuario.

## Sistema de liquidación de salario
### Enunciado

Una empresa necesita desarrollar un programa que le permita calcular el salario final de sus empleados al final de cada periodo de pago.

El sistema debe solicitar la siguiente información para cada empleado:

Nombre del empleado
Número de horas trabajadas
Valor de la hora de trabajo

A partir de esta información, el programa debe:
```text
* Calcular el salario base del empleado.
* Determinar si el empleado tiene derecho a horas extras (más de 40 horas trabajadas).
* Calcular el pago adicional por horas extras, teniendo en cuenta que estas se pagan con un recargo.
* Aplicar un descuento de seguridad social sobre el salario total.
* Mostrar un resumen detallado del pago del empleado.
```

El programa debe permitir procesar varios empleados consecutivamente y, al finalizar, mostrar:

El total de empleados procesados
El valor total pagado por la empresa

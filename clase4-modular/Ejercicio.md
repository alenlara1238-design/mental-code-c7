# Ejercicio: Control de préstamo en biblioteca

Diseñar un algoritmo modular para controlar el préstamo de libros en una biblioteca.

El sistema debe:

1. Solicitar la edad del usuario.
2. Verificar si puede obtener préstamo:
   - Si tiene 12 años o más, puede prestar libros.
   - Si tiene menos de 12 años, no puede prestar libros.
3. Mostrar el resultado de la validación.

El problema debe resolverse utilizando programación modular, separando la solución en los siguientes módulos:

- Un módulo para obtener la edad del usuario.
- Un módulo para validar si el usuario puede prestar libros.
- Un módulo para mostrar el mensaje final.
